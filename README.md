# OdooIndex Connector for Odoo

Stay on top of your Odoo instance's modules and migration readiness with **OdooIndex.com**.

## What it does

The **OdooIndex Connector** automatically uploads a list of your installed modules to your [OdooIndex.com](https://odooindex.com) account, then downloads the latest update and migration information for your target Odoo version — so you always know which modules are ready to upgrade and which need attention.

## Why use it

- **Know before you upgrade** — see at a glance which modules are ready for the next Odoo version and which ones still need work.
- **Centralized visibility** — track every connected Odoo instance's module inventory from your OdooIndex account, or view it directly inside Odoo.
- **Stay current** — get the latest available versions and the open pull requests that matter for the modules you rely on.
- **Privacy-first** — only module metadata is sent. No business data, documents, customer records, or user information ever leaves your server.
- **Simple setup** — pair your instance in a few clicks and let the built-in scheduled action keep everything in sync.

## Get started

1. Add this repository to your Odoo ``addons_path``.
2. Install the ``odooindex_connector`` module.
3. Go to *Settings → General Settings → OdooIndex Connector* and pair your instance with OdooIndex.

For the full technical details, configuration and API contract, see [odooindex_connector/README.rst](odooindex_connector/README.rst).
